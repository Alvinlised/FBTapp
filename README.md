# FBT Trip Logbook support website

Static website source is in `docs/`:

- `index.html` — overview
- `support.html` — support and troubleshooting
- `privacy.html` — privacy policy for the current iOS 1.0 build

## Before publishing

Support and privacy contact: fbt@outbacklifting.com.au. Website content is ready for hosting; verify the live URLs after enabling Pages.

Enable GitHub Pages under Settings → Pages, choose Deploy from a branch, then `main` and `/docs`. Keep the repository's current privacy setting. GitHub Pages for private repositories requires an eligible paid plan. Do not make the repository public without the owner's explicit authorization.

The intended Pages URLs are `https://alvinlised.github.io/FBTapp/support.html` and `https://alvinlised.github.io/FBTapp/privacy.html`; they are not confirmed live until Pages deploys successfully.

This repository contains only support website source. The iOS app project is maintained separately. Review the privacy policy whenever the app's SDKs, network behavior, storage or features change.
